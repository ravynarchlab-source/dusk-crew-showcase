# Credits

Dusk Crew is made by RAVYN.

## Our own work

Models, animation, shaders, effects and interface are built by our own scripts and code. No generative-model output (image, 3D, audio or voice generators) is used anywhere in the game or on this page.

## Free sources used in the game

Each file is logged with its source and licence in the project's licence register.

CC0 needs no credit. We list the sources anyway.
